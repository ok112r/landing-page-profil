Simulasi & Sensor Platform: Arduino

LAPORAN PRAKTIKUM SENSOR KELEMBAPAN TANAH MENGGUNAKAN SENSOR SOIL MOISTURE

Simulasi dan perancangan alat pendeteksi kelembapan tanah menggunakan mikrokontroler ESP32 dan sensor soil moisture pada platform arduino. Sistem dilengkapi peringatan dini melalui alarm buzzer dan notifikasi otomatis menyalakan air.

Alur Kerja & Arsitektur Sistem:

  • › Akuisisi Data: Probe sensor kelembapan tanah mengukur resistansi kadar air secara analog dan diteruskan ke pin ADC ESP32.
  • › Otomasi Aktuator: Mikrokontroler memicu modul relai untuk menyalakan pompa air secara otomatis saat kelembapan berada di bawah ambang batas minimum.
  • › Peringatan Terpadu: Mengaktifkan alarm audio via buzzer lokal serta mengirimkan notifikasi peringatan otomatis ke aplikasi Telegram pengguna via Bot API.

Smart Otomotif Simulator: Wokwi

RANCANG BANGUN SMART RIDE MODE SYSTEM BERBASIS MICROKONTROLER UNTUK OPTIMASI RESPON THROTTLE MOTOR LISTRIK

Prototipe sistem manipulasi sensor throttle pada motor listrik sehingga gas pada motor dapat diatur menjadi 3 mode (race, normal, dan rain), jadi pengguna bisa menyesuaikan kecepatan motor listrik sesuai kebutuhannya.

Penerapan Logika Kendali 3-Mode:

  • › Manipulasi Sinyal Throttle: Membaca tegangan analog dari throttle grip motor lalu memetakannya kembali (mapping) sesuai profil algoritma mode aktif.
  • › Rincian Karakteristik Mode:
    • Race Mode: Akselerasi agresif 100% respons gas untuk performa puncak.
    • Normal Mode: Karakter seimbang untuk efisiensi baterai harian.
    • Rain Mode: Pembatasan respons akselerasi secara lembut untuk mencegah selip roda di jalan basah.
  • › Verifikasi Simulasi: Diuji secara komprehensif menggunakan simulator mikrokontroler Wokwi dengan pemodelan Arduino Nano.

Assistive IoT AM TECHNOLOGY Jogja

Sistem pendeteksi benda untuk orang buta dengan sensor lidar dan buzzer

Pengembangan solusi Internet of Things bersama AM TECHNOLOGY Jogja, meliputi perancangan sistem pendeteksi benda dan lingkungan untuk mendukung teman2 penyandang tunanetra, dengan sistem memanfaatkan sensor lidar dan mengirimkan suara melalui buzzer.

Implementasi & Teknologi Asistif:

  • › Kolaborasi Industri: Dikembangkan bersama tim startup IoT AM TECHNOLOGY Jogja sebagai solusi teknologi asistif berdampak sosial nyata.
  • › Sensor LiDAR: Menggunakan transmisi sinar laser optik LiDAR untuk memindai kontur dan halangan fisik dengan tingkat presisi tinggi dan latensi instan.
  • › Umpan Balik Akustik: Frekuensi dan interval bunyi buzzer berubah otomatis menyesuaikan jarak halangan, memandu teman-teman tunanetra secara intuitif saat berjalan.

Web & Server IoT ESP32 Server

Rangkaian monitoring jadwal sholat mushola berbasis web dengan esp32 sebagai server

Pemodelan dan simulasi rangkaian IoT menggunakan kombinasi smart tv dengan memanfaatkan esp 32 sebagai penghubung dengan server dan mengambil signal dari wifi secara jauh atau online, dan bisa menampilkan jadwal sholat secara real time.

Arsitektur Web Server & Smart Display:

  • › Desain Perangkat Keras: Mencakup perancangan tata letak jalur PCB kustom, integrasi display LCD, dan dukungan aplikasi Android Studio untuk monitoring konfigurasi.
